為什麼 AI 總是丟三落四？

MEMORY BURDEN

記憶體極限的瓶頸

  • 資訊超載 ── 一次把所有的 SOP、家規、工具全部塞在對話裡，大腦就會陷入資訊爆炸，導致注意力分散。

ATTENTION DILUTION

  • 規則稀釋 ── 當對話歷史拉長，AI 就會開始遺忘先前交代的限制，開始裝傻、跳步。
  • AI 敷衍發懶 ── 沒有物理性的 SOP 強制，AI 遇到複雜步驟就會自主省略，導致執行失敗。

一分鐘認識 Markdown · BASICS

別怕，Skills 用的
就是 Markdown

Markdown 是什麼？ 一種用純文字符號標記格式的寫法，像記事本一樣簡單。不需要任何程式基礎，用 # 標題、- 列點、**粗體** 就能寫出結構化的文件。
// Markdown 語法 → 對應效果
# 大標題　　　→　最大的標題
## 二級標題　　→　次級標題
**粗體文字**　→　粗體文字
- 列點項目　　→　• 列點項目
1. 編號項目　→　1. 編號項目
---　　　　　　→　分隔線
FOR AI

AI 讀 Markdown 的 # 和 ## 就像人類看目錄，瞬間抓到重點結構

FOR HUMAN

不需要學程式，用記事本就能編輯。GitHub、Notion 也通通用它

照妖鏡一：Skill 載入失敗怎麼辦？

SYNTAX & FILEPATH CHECK

語法與檔案路徑校驗

  • YAML 語法檢查 ── YAML 元數據的短橫線 --- 是否成對閉合？縮排是否使用了非法 Tab 空格？語法錯誤會導致整個卡片報廢。
  • 路徑層級確認 ── 檔案是否精確放在 『~/.claude/skills/my-skill/SKILL.md』？子目錄名稱是否與貼紙中的 name 變數 100% 對齊？
INTENT TRIGGER OPTIMIZE

意圖描述與觸發詞優化

  • description 關鍵字匹配 ── 在 YAML 描述中加入明確的觸發關鍵字，如「開立電子發票」、「會議逐字稿總結」，幫助 AI 進行背景靜默意圖命中。
  • 防呆與手動喚醒 ── 若 AI 裝傻，可以在對話中手動輸入「請幫我使用 『issue-invoice』 技能開立發票」，強行指示 AI 讀取指定卡片。

# IG Reel Downloader

## 何時使用此 skill
- 使用者貼上 instagram.com/reel/ 連結
- 提到「下載 IG」「存這個 reel」「下載 Instagram」

## Critical SOP
1. 執行 bash scripts/ensure_dirs.sh 確保分類目錄存在。
2. 跑 bash scripts/probe.sh <URL> 抓取影片 description。
3. 依主題判斷分類（生態、美食、旅遊、知識、生活、迷因）。
4. 跑 bash scripts/fetch.sh <URL> <分類> 下載到對應目錄。

## Important
- 若 yt-dlp 未安裝，提示並中斷流程。
- 若同名檔案已存在，提示「已存在」並跳過。
SEMANTIC CATEGORIZATION 智慧語意分類

AI 讀完影片 metadata，自動將影片歸類到美食、生態等子資料夾，省去手動分類！

TOOL DELEGATION 大腦與雙手協同

AI 負責聰明的語意判斷，並將實體影片下載與目錄操作交給 bash 腳本，穩固自動化！
